## 一、代码修复

### 1.1 HTTP API 字段名修复

**问题：** `/api/v1/group-members` 接口返回字段名与文档不一致

**修复前：**
```typescript
// electron/services/httpService.ts L1330
members: result.data.map((member) => ({
  accountId: member.username,  // ❌ 错误字段名
  // ...
}))
```

**修复后：**
```typescript
members: result.data.map((member) => ({
  wxid: member.username,  // ✅ 与文档一致
  // ...
}))
```

**影响：** 按照文档编写代码的客户端现在可以正确解析 `wxid` 字段。
